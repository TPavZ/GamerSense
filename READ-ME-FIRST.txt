GamerSense v0.4.21 - gunfire volume control

INSTALL
Stop the old app. Extract the whole App ZIP into a NEW folder and launch
GamerSense.exe. Requires the .NET 9 Desktop Runtime. Source builds use the
.NET 9 SDK and the unchanged BUILD-DEBUG.bat.

WHAT CHANGED
Gunfire now has a separate 0-150% slider alongside Overall, Explosions,
Footsteps, Ground vehicles and Air vehicles. 100% is normal; 0% mutes a
routed section. Gunfire values are remembered and included in Reset all.
Existing settings load with Gunfire at 100%, preserving other slider values.
Category routing still starts OFF each time the app opens.

TEST
Keep your working Direct cable capture setup: game to CABLE Input;
GamerSense input CABLE Output; true output Speakers (C6).
Open Volume controls, start playback, and enable Apply category volumes.
Leave all sliders at 100% initially. Then try Gunfire at 70%, with the others
at 100%, while watching for Estimated section: gunfire. Sustained firing
is a better first test than isolated shots. Toggle category volumes off to
compare. Boosts above 100% can clip loud audio.

LIMITS
This preview changes the WHOLE mixed section classified as gunfire;
overlapping footsteps, voices or vehicles in that section change together.
It does not separate simultaneous sources. Short shots may finish before
the estimate arrives. Gunfire uses the existing combined profiles with a
distance limit derived from 2,252 positive weak-label windows, the same
runner-up margin and two-fresh-estimate policy as other routed categories.
Those heuristics are not calibrated confidence or validated cross-game
accuracy. Unknown/stale/gap fallback and bounded holds remain unchanged.
No capture/output buffer or lookahead was added. The existing smooth gain
ramps remain in use. At all sliders 100%, output remains byte-identical.
Captured samples, analysis and approved exports use original pre-volume
audio. Device memory and playback timing remain unchanged.

VALIDATION
Debug and Release builds: zero warnings/errors. Audio checks passed for
native unity, stereo gain, gunfire routing, stale/unknown/off fallback,
smooth ramps, legacy setting defaults, JSON round-trip and gain bounds.
UI checks passed for six sliders, saved gunfire edits and reset. The rendered
volume screen was inspected. Existing capture, review/export and low-delay
playback checks passed. Listening quality and recognition need game testing.
