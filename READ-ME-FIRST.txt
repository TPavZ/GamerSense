GamerSense v0.4.10 — direct refill test

Close the old app, extract the ENTIRE app ZIP to a new folder, open GamerSense.exe.
Select Direct refill (test) while stopped, then Start.
Compare delay and quality during 2-3 minutes of continuous audio.
Stop and Copy audio details, including LEAN OUTPUT and PLAYBACK SUPPLY.
The fill policy should say Available captured samples only.
If it crackles or drops out, return to Lean output (test) while stopped.
All earlier modes, device/mode memory and the black/teal/gold icon are retained.

C6 reported a fixed 10 ms shared period. Direct refill keeps that output target
and the 10 ms startup reserve, but queues only available captured frames rather
than precommitting silence when capture runs short. New samples wake playback.
No samples are discarded, reordered, filtered, or amplified.

Refill attempts waiting for capture are counted separately. Windows can still
emit silence if its queue empties; these are not measured audible glitch counts.
The silence-fill metric excludes waits. Actual quality and total delay require
listening tests; this update does not promise zero delay.

SOURCE: Build using BUILD-DEBUG.bat, then launch the built GamerSense.exe.

EVENT REVIEW: The latest 60 seconds are retained for reviewing spikes.
Mark with the button, Ctrl+Alt+F8 if available, or F8 within this app.
Select a marker, Load / refresh event clip, stop playback before Replay range.
Choose a label and Keep/Reduce/Unsure, then Save WAV + label. Keep both files.
Sound suppression is not implemented. Offline demo: Open audio sample > demo-vehicles.wav.
