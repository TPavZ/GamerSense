GamerSense v0.4.11 - direct cable capture comparison

1. Extract this entire ZIP into a new folder.
2. App ZIP: open GamerSense.exe. Source ZIP: run BUILD-DEBUG.bat,
   then open src/GamerSense/bin/Debug/net9.0-windows/GamerSense.exe.
   The app needs the .NET 9 Desktop Runtime; building needs the .NET 9 SDK.
3. Turn OFF Windows Listen to this device for CABLE Output.
4. Choose playback mode: Direct cable capture (test).
5. Choose GAME AUDIO / VIRTUAL DEVICE: CABLE Output (VB-Audio Virtual Cable).
6. Choose TRUE OUTPUT: Speakers (C6).
7. Keep the game/test video's audio output on CABLE Input.
8. Press START GAMERSENSE. Verify clean audio first.
9. Replay GamerSense-delay-test.avi using the same player and volume.
   Record the screen and speakers with the phone in the same position.
10. Send the recording labelled v0.4.11 Direct cable capture, along with
    Copy audio details from this session (during playback or after Stop).

This is an optional comparison mode, not a confirmed delay reduction.
It reads the cable's recording endpoint instead of playback loopback.
Direct refill playback settings, spectrum, matching, event review and icon
are retained. No gain changes or sound filtering have been added.

If audio crackles or fails, Stop, select Direct refill (test), confirm
CABLE Input and Speakers (C6), and Start. Existing input memory is separate.
Keep Windows Listen off while running GamerSense.

Validation: Debug/Release builds passed with zero warnings/errors;
automated playback, analysis, settings and event-review checks passed.
Real-device audio quality and audible delay still require your test.
