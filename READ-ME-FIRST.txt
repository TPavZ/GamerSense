GamerSense v0.3.2
Build with BUILD-DEBUG.bat, then launch the built GamerSense.exe.

Includes stricter reload rules, ambience/mixed fallback, and background sample
decoding. The original playback buffer values remain. This is not a measured
latency fix: use the Queued audio readout to help check for increasing backlog.
That readout excludes device/output latency. See README.md for testing details.

Developer checks: dotnet run --project tests/AnalyzerChecks/AnalyzerChecks.csproj

Retraining with Python and NumPy:
1. Put validation/reviewed-labels.json into the extracted Wardogs-samples folder.
2. python validation/train_live_model.py Wardogs-samples Wardogs-model-results
3. python validation/apply_rejection.py Wardogs-model-results
4. The gated model is Wardogs-model-results/prototype-model.json.
No source audio is changed. New c1/c2/c3 clips remain unverified/untrained.
