GamerSense v0.3.3
Build with BUILD-DEBUG.bat and launch the built GamerSense.exe.
Stop playback, select Lower latency (test), then Start to test shorter buffers.
If audio crackles, Stop, select Stable playback, and Start again.
Click Copy audio details while playing and paste the text into the chat to
help diagnose delay. Requested and measured queue/batch values do not equal
full end-to-end latency. See README.md for validation and timing details.

All v0.3.2 matching and observer fixes are included. Remembered device IDs are
preserved. Developer checks: dotnet run --project tests/AnalyzerChecks/AnalyzerChecks.csproj
