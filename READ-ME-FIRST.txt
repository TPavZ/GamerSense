GamerSense v0.4.7 — minimum-delay test

Close the old app, extract the ENTIRE app ZIP to a new folder, open GamerSense.exe.
Select Minimum delay (test) while stopped, then Start.
Compare delay and quality during 2-3 minutes of continuous audio.
Stop and Copy audio details, including WINDOWS STREAM SETTINGS and PLAYBACK SUPPLY.
If audio crackles or drops out, return to Event-driven capture while stopped.
That mode retains the clean v0.4.6 settings. Stable is also available.

Minimum delay requests capture 20 ms, output 10 ms, startup prebuffer 20 ms,
capacity 80 ms. Actual Windows allocations may differ. It is not a claim of
zero latency. Silence-fill counts include source pauses; test with continuous audio.
Device and playback mode memory and the black/teal/gold icon are retained.

SOURCE: Build using BUILD-DEBUG.bat, then launch the built GamerSense.exe.

EVENT REVIEW: The latest 60 seconds are retained for reviewing spikes.
Mark with the button, Ctrl+Alt+F8 if available, or F8 within this app.
Select a marker, Load / refresh event clip, stop playback before Replay range.
Choose a label and Keep/Reduce/Unsure, then Save WAV + label. Keep both files.
Sound suppression is not implemented. Offline demo: Open audio sample > demo-vehicles.wav.
