GamerSense v0.4.9 — low-period shared output test

Close the old app, extract the ENTIRE app ZIP to a new folder, open GamerSense.exe.
Select Low-period output (test) while stopped, then Start.
Compare delay and quality during 2-3 minutes of continuous audio.
Stop and Copy audio details, including LEAN OUTPUT and PLAYBACK SUPPLY.
The report shows supported/selected shared engine periods, or a fallback reason.
If it crackles or drops out, return to Lean output (test) while stopped.
All existing modes, device/mode memory and the black/teal/gold icon are retained.

This mode queries IAudioClient3 for supported shared engine periods and requests
the shortest one below the default, using matching native float32 mono/stereo.
On unsupported drivers/formats/initialization it uses Lean rendering and reports
that fallback. Startup reserve remains 10 ms. Output capacity follows the
selected period; the 30 ms allocation request applies only to fallback.
Only available captured samples are queued in low-period rendering; waits for
source are counted separately from silence fill. Neither is a definitive glitch
count. No claim of zero or measured end-to-end latency is made.
C6 driver support, audible latency and sound quality require the user's test.
